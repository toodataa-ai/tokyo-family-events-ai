# 杉並区全ジャンル固定サイト収集・重複統合（2026-10-21）

- 旧 `suginami_festival` は削除・変更・無効化しない。
- 新 `suginami_calendar_all` は公式の全ジャンル月別一覧に加え6週間の全42日の日別一覧を取得する。月別上位5件等を網羅性の証拠としない。
- 固定サイト内の `/sNNN/event/NNNNN.html` を公式ページIDで全候補化する。ファミリー適性の判定は後段、個々の日時・予約・変更・取消の公式確認が別途必要。
- 月別/日別にHTTPエラー・HTML異常がある場合、未確認として報告し、0件として扱わない。取得=候補発見であり、掲載済み・全件採否完了ではない。
- 同一イベントは名前・開催日・区に加え具体的な共通会場アンカーを要求する。別会場の同名催しは残す。画面統合は元のIDを保つ。統合元のデータファイルは削除しない。
- 10/24の花と緑の井草祭り(ID28531)・10/25の杉並清掃工場環境フェア2026(ID28567)を固定サイト取込の回帰事例とする。公開候補と最終掲載判断は、公式詳細ページと個別採否を検査してから。
- 既存レコードの物理削除・同一週ID削除は不可。動的データの修正は data-staging の別ゲート、productionはユーザー承認後のアプリ公開ゲート。
- 将来の23区展開は各サイトに専用アダプターを設け、一覧件数・候補ID・採否件数の一致を必須とする。
