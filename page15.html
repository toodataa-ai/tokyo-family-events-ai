すべては、一本のレーヨンから始まった。100年の挑戦のはじまりをたどります。

実は、ここにも東レの素材。東レの素材がもたらした、暮らしの変化を発見してください。

素材は、人々の「つくりたい」という想いをかきたててきました。素材と人類がともに歩んできた発展の軌跡をたどります。

素材のもつ不思議な力に触れ、それを生み出す東レの探究心（WONDER）を感じていただきます。

人のこと、社会のこと、地球のこと。美しい世界の映像とともに、東レが思い描く未来への想いをご紹介します。

    吉泉 聡

    TAKT PROJECT 代表
    デザイナー

    COMMENT

    東レの研究所を訪れ、研究者の皆さんとの対話から企画展づくりが始まりました。
    そこで出会ったのが「極限追求・超継続」という言葉です。一つの問いを深く掘り下げると、新しい発明や発見が生まれる。その姿勢こそ、東レの真髄なのだと──。

    一つわかると、また一つわからなくなる──。
    その終わりのない営みから浮かび上がった言葉が、“WONDER”です。
    そして、そのWONDERは、人の「つくりたい」という好奇心を呼び覚ます、新しい素材にも宿っているように感じます。

    世界への “WONDER” が、新しい素材となり、さらに次の “WONDER” を生み出していく。
    この企画展を通して、その循環を感じていただけましたら幸いです。

    PROFILE

    TAKT PROJECT代表。デザイナー。 既存の枠組みを揺さぶる実験的な自主研究プロジェクトを行い、ミラノデザインウィーク、デザインマイアミ、パリ装飾美術館、21_21 DESIGN SIGHT、香港M+など、国内外の美術館やデザインの企画展で発表・招聘展示。その研究成果を起点に、様々なクライアントと「別の可能性をつくる」多様なプロジェクトを具現化している。

    東レの印象としては、人を大切にし、長期的な視点で人を育てる文化が根付いていることが大きな点だと感じています。

三澤 遥 ＋
三澤デザイン研究室

日本デザインセンター
デザイナー

COMMENT

素材を新しいものへ置き換えるのではなく、まずその素材が元から持っている可能性を見つめ、引き出す。肉眼では見ることのできない極小スケールの糸にも、伸びる、消える、滑る、縮むといった、生まれ持った個性が備わっています。その違いは、眺めているだけではわかりません。実際に触れて、試して、観察することを繰り返すことで、アイデンティティはくっきりと浮かび上がります。「こんなことができるのね」と語りかけるように素材と向き合うこと。必要以上に手を加えず、その性質を活かすことこそ、これからの地球との向き合い方につながると考えています。

PROFILE

日本デザインセンター三澤デザイン研究室室長。武蔵野美術大学准教授。デザインオフィスnendoを経て、2009年より日本デザインセンター原デザイン研究所に所属。2014年より同研究室として活動開始。

ものごとの奥に潜む原理を観察し、そこから引き出した未知の可能性を、実験的なアプローチによって視覚化する試みを続けている。主な仕事に、水中環境を新たな風景に再構築した「waterscape」、かつてない紙の可能性を探求した「動紙」、国立科学博物館の移動展示キット「WHO ARE WE」がある。2026年4月、イタリア・ミラノのADI Design Museumにて個展「bit by bit」を開催した。

  • https://www.ndc.co.jp/
  • https://misawa.ndc.co.jp/

武井 祥平

nomena
エンジニア

COMMENT

このプロジェクトがスタートしてまもなく、東レの素材について詳しいレクチャーを受けるために、愛媛、滋賀、静岡、名古屋にある4つの研究所を訪問しました。印象的だったのは、どの研究者も東レの素材の面白さを屈託のない笑顔で語ってくれたことです。その裏側には、素材の研究を通して、この世界の不思議や美しさをもっと知りたいという純粋で情熱的な探究心が感じられます。今回nomenaは、1971年に東レが世界に先駆けて商業生産に成功した炭素繊維に注目しました。多くの困難を前に炭素繊維の可能性を信じて研究を続けてきた人々の心を、炭素繊維によって表したいと考えています。

PROFILE

2012年設立。日々の研究や実験、クリエイターやクライアントとのコラボレーションを通して得られる多領域の知見を動力にして、前例のないものづくりに取り組み続けている。

主な仕事に、宇宙航空研究開発機構JAXAなど研究機関との共同研究や、大阪・関西万博ブルーオーシャンドーム 水のアートピース制作、東京2020オリンピック・パラリンピック聖火台の機構設計、セイコーウオッチとの共同作品『時計の捨象』など。

主な受賞歴に、毎日デザイン賞（2025）、日本空間デザイン賞銀賞（2023）、文化庁メディア芸術祭アート部門優秀賞（2022）他。

COMMENT

カーボンファイバーはこれまでも使用してきましたが、リサイクル材から生まれたカーボン不織布の存在には驚かされました。構造的な性能はもちろん、一般的なカーボンの織物とは異なる、黒い和紙のような繊維の質感にも強く惹かれました。茶室という着想も、この素材との出会いから生まれたものです。最先端の技術と、日本人の身体感覚に寄り添う繊細な空間が共存することで、再生素材が新たな美しさや文化的価値へと変わる。その可能性を、ぜひ多くの方に体験していただきたいです。

PROFILE

Nature Architects
CTO

COMMENT

東レの技術に触れ、材料開発や微細スケールの構造設計が生む新たな物理特性が社会の価値に直結していることに感銘を受けました。その背景には膨大な試行錯誤と探索があり、未知の素材の可能性を探る情熱を感じます。本作品は「シワ」という変形現象を題材に、無秩序から多様な秩序が立ち現れる過程そのものを見せています。素材開発とは世界に異物を持ち込むのではなく、世界に内在する「あり得る素材」から、人や社会、環境に価値をもたらす秩序を選び取る行為ではないでしょうか。作品を通して、感覚に触れていただければ幸いです。

PROFILE

「あらゆる製造業を設計から革新する」をミッションに、物理現象を制御する形状を計算機によって導き出す独自技術「Generative Engineering™」を開発し、さまざまな業界に対して設計ソリューションを提供。形状・材料・物理現象の関係性を読み解きながら膨大な設計空間を高速かつ広域に探索することで、従来の発想や試行錯誤だけでは到達出来ない設計解の導出を実現している。
未踏IT人材発掘・育成事業 スーパークリエータ認定、2024ソフトウェアジャパンアワード受賞。
