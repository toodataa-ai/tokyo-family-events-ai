## 文字と画像
- タイトルは1行80〜82px・2行70〜74pxを初期目安。本文は**46pxから2px刻みで実測し**、通常37〜46pxの範囲で最大化。文字配置の目安は元テンプレートの本文幅540px。必要なら公式事実を損なわず短文化し、会場・日時・写真との重なりを禁止。
- 書体を役割ごとに統一。連携APIでfont_family変更が不可能なら未完了と正確に報告する。ユーザーの明示承認なくテキストを画像化しない。
- 画像の優先順位：当年のイベント専用公式画像→当該公式ページの適切な掲載画像/共通OGP→当年の当該イベントチラシPDF画像→画像準備中。元の画像URLが失敗しても公式イベントページ/添付PDF/主催者サイトから再探索する。
- 出典欄は「出典：〇〇」と表記、ページURLも記録。公式サイト共通素材はイベント写真と誤認させない。
- **出典を示すだけで著作権者の利用許諾にはならない。** 許諾不明の場合は非公開ドラフトの候補利用までとし、Instagram公開・配布は行わない。
- 公式情報にない日時・料金・予約条件を創作しない。掲載年、イベント、会場との一致を確認。
