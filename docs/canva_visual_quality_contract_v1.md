## 文字のロール別契約
1. 同じロール（イベントタイトル/日時/会場/本文/出典）は、**全イベントで同一フォントファミリー・ウェイト・色・基本行間**。同一ロールの表示条件が同じなら同じサイズ。変えるのは収まりに必要な最小限だけ。
2. 基準書体は既存テンプレートのイベント紹介ページの同一ロールのテキスト要素から継承。**書体名を取得・設定できないAPIでは「全ページのフォント統一済み」と断定しない**。Canva画面の確認が必要ならその旨を残す。勝手に画像化して編集性を失わせない。
3. タイトルは1行80〜82px、2行70〜74pxを**初期目安**として枠内最大化。文字数が長い場合は改行を優先し、著しく縮小する前に本文を整理。文字切れは禁止。
4. 説明本文はまず46pxを試し、実測bounding box・行数・高さが収まるまで2px刻みで調整（通常37〜46px）。上段/下段で同じ条件なら同じサイズを優先。**フォントサイズだけでなく実際に読めるか**をプレビューで確認。
5. 会場・日付・時間・料金・出典は、役割内で大きさ/位置の連続性を維持しつつ可能な限り大きくする。ただし本文より低優先の出典が読めなくなるほど縮小しない。
6. テキストとフレームの内側には目安16px以上の余白、独立したテキスト領域同士の間は目安12px以上。元テンプレートの意図した重ね表現は保持しても、読めない重なりは禁止。
7. イベントごとに配置位置が上下左右へ勝手にずれないこと。例外調整は必要最小限とし、次ページにも同じ基準を適用。

## 画像・出典の契約
1. 優先：**当年の当該イベント公式画像 → 当該公式ページに表示された適切な画像（共通OGPを含む） → 当年・当該イベントの公式チラシPDFの1ページ目を画像化 → 適切な素材が見つからない場合のみ「画像準備中」**。
2. 元データの画像URLが使えないときは、それで探索終了にしない。公式イベントページ・主催者ページ・PDF添付・ページ内のimage/og:imageを調べ、取得失敗時は別の公式導線を試す。
3. 画像は本人撮影/開催年/イベント名/会場との整合性を確認。**別イベント画像、前年告知、過去コピーに残った画像の流用、架空画像での穴埋めは禁止**。
4. 元テンプレートの写真フレーム内でアスペクト比を保ち、過度の引き延ばし・重要な文字や被写体の不自然な切れを避ける。ダウンロード成功/Canvaへアップロード成功/配置成功/表示成功はそれぞれ別に検証する。
5. 各写真の近くに「出典：媒体・施設・主催者名」を読み取れるサイズで記載。画像種別が共通OGPなら「公式サイト共通画像」と明記。元ページURLをイベント単位で証跡保持。写真がない場合は出典の虚偽表記をしない。
6. **出典表記のみで著作権者の転載許諾が得られるわけではない**。掲載権利未確認の画像はユーザー確認用の非公開Canvaドラフトに限る。Instagram/SNSへの投稿・公開・配布は別途確認まで行わない。

## 作業手順（この順に）
1. 依頼で指定された表紙タイトル・選択件数・並び順・公式情報を固定。**元テンプレートから必ず新しいコピー**を作成し、そのIDと編集URLを記録。
2. 選択番号1〜Nを全紹介ページの上下枠へ順番どおりに入れ、使わない枠を装飾も含めて非表示。過去イベントが1文字でも残ったら修正。
3. イベントごとに画像探索・取得・Canva素材取込・フレーム配置・出典表記まで実施。未配置なら「何を試し、どこで失敗したか」を個別記録し、画面に理由を残す。
4. 全枠で同じロールの書体・ウェイト・行間・余白を照合。本文を最大化し、日時・会場・説明・出典の正確性と見切れを確認。
5. 完成デザインのすべての**プレビュー画像を出して目視点検**（必要に応じて拡大）。変更後に再プレビューする。可能なら参照Instagram投稿と見比べる。ただし参照が取得できなければ「比較未実施」と記録。
6. 下記の合格検査を確認し、Canva連携が保存の追加承認を求めるならユーザー承認を得てから、**コピーのみ保存**。編集リンクと未解決の項目を返す。

## 合格ゲート（必須）
- G01: デザインが新規コピーで、元・旧版は変更なし。
- G02: 1080×1350、必要ページ数（7〜17＝max(7, 2+ceil(N/2))）、指定件数と並び順、表紙「N選」一致。
- G03: 全紹介ページの各使用枠には該当イベントの本文・会場・日時・料金・画像または正当な準備中表示。**旧イベント残存ゼロ**。未使用枠は全要素非表示。
- G04: 使用画像すべてにイベントと一致する元ページURL・「出典：」があり、他イベント/別年/著作権許諾済みの偽装がない。
- G05: 各テキストのbounding boxで重なり、切れ、ページ外はみ出しがゼロ。タイトルと本文が指定上限内で読みやすく、同じロールの見た目が揃っている。
- G06: 生成した全ページの編集後プレビューを目視で検査。フォントファミリーが確認できない場合は「未検証」と報告し、**検証済みと偽らない**。
- G07: 完成後Canvaコピーの保存成功と編集URLを確認。SNS公開はしない。
- G08: 画像が「準備中」の場合には探索経路・失敗段階・公開前の代替確認を記録。準備中ゼロを根拠なく約束しない。
- **重大NG**: 元の編集、旧画像/旧文章残存、別イベント写真の混入、出典偽装、誤日時、文字の欠け、SNS無断公開。重大NGが1件でもあれば完成扱い不可。
- Canva連携の能力制約があるときは、その項目を「未完了/要手動確認」と明示し、他の項目は完了まで進める。**作業途中で完成宣言しない**。
